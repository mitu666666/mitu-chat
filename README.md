# 迷途 · 个人主页

Bootstrap 5 单页个人主页，静态部署在 Vercel。

- 在线地址：<https://mitu1.vercel.app>
- 源码：单文件 `迷途.html`，无构建步骤、无依赖安装

## 特性

- 响应式布局，移动端自适应
- Bootstrap 5.3 + Font Awesome 6.4（使用国内 CDN 镜像）
- 社交链接集中管理，便于替换为真实账号
- 主题配色与个人信息模块分离，修改成本低

## 使用方法

```bash
git clone https://github.com/mitu666666/mitu-chat.git
cd mitu-chat
```

随后直接用浏览器打开 `迷途.html` 预览，或推送到任意静态托管（Vercel / GitHub Pages / Nginx 均可）。
